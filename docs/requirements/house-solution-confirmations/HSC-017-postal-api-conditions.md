# HSC-017: Postal-Code API Operating Conditions

- Status: Not yet asked
- Decision owner: House Solution

## Confirmed Context

The selected direction is Japan Post's official Postal Code and Digital Address API for property and homeowner entry. Local manual entry remains available until integration is ready.

## Questions

1. Who enters into and owns the API agreement and credentials?
2. What availability, cost ceiling, rate limits, support, and failure procedure are acceptable?
3. When must the integration be available relative to production release?

## Affected Documents

Address requirements, external-service boundaries, secrets, operations, cost, and tests.
