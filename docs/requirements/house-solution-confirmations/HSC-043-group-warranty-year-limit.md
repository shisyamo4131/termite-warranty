# HSC-043: 保証グループ別の最大保証期間と選択制限

## 2026-10-22 保証グループ上限の保存時適用

オーナーが設計・実装・データ補完・Local検証・Dev配備を承認。`warrantyGroups.maxWarrantyYears`を数値10／20／30で設定し、初期値はUH10、HSC／SHS30。名称による保証年数の判定は廃止する。未設定・不正値は30年へ推測補完せず登録・編集・取込みを拒否する。

追加指示により、グループ設定変更時に既存物件を照会・整合検査しない。物件の登録（下書きを含む）・編集と取込みで最新のグループ上限を検証し、選択した`maxYears`を物件へ保存する。この既存項目が保存時の上限であり、延長は保存済み`maxYears`だけで判定する。グループ変更だけで既存物件の`maxYears`・保証年数・期間・満了日を書き換えない。既に付与した年数未満への物件上限変更は従来どおり拒否。最新グループ上限が既付与年数を下回る場合は編集保存を拒否し、期間を短縮しない。

補完は既存3グループの未設定項目だけ。物件・採番・履歴・設定・アカウントは変更しない。グループID／名称／接頭辞／年度開始月を事前照合し、既存値が競合する場合や読取り後に入力が変わった場合は停止。原像の要約hashと物件不変を照合する。コード切戻し時にも補完項目は旧版に無害なので維持し、データを自動巻戻ししない。Prod配備・正式投入・バックアップ等は保留。

検証・配備の完了状態は[運用記録](../../operations.md)を参照。

## 実装を確認した結果

「制御がない」は一部相違する。保証グループに最大保証期間の設定項目はなく、物件画面は全グループで10／20／30年を提示し、新規の初期値は20年。既に延長した年数より小さい選択肢だけを無効にしている。一方、UHには以下の保存・取込み制限がある。

| 場所 | 現行の制御 |
| --- | --- |
| 本登録 | 実際の保証グループ名がUHなら、最長保証期間が10年以外の登録を拒否 |
| 既存物件の編集 | 保存済みのグループ名がUHなら、10年以外の保存を拒否 |
| 新規下書き | 本登録時までグループ名を保存しないため、通常の新規下書きには上記UH判定が掛からず、共通の10／20／30年の検証のみ |
| 延長 | グループ設定ではなく、物件の現在年数と最長保証期間で判定。正しく10年上限で登録されたUHは延長できない |
| 増分CSV取込み | グループ名UHを判定し、10年以外を拒否 |
| 初期過去データ取込み | UHを10年として抽出し、取込み計画でも10年以外を拒否 |

確認基準は `cf7395440b0c76a46156aaa151ce500b51c467cc`。根拠は `app/components/MeetingPrototype.vue` のグループ編集・`maxYearsOptions`・新規初期値、`functions/property-warranty.js` の `groupName`／`group.name` によるUH判定と延長処理、`src/domain/property-bulk-import.mjs` のUH検証、`scripts/extract-historical-intake.py` と `scripts/lib/historical-intake-plan.mjs` のUH取込み制約。ソース調査であり、Dev実データの全件検査や画面受入れの結果ではない。

## 検討する案

保証グループに「選択を許容する最大保証期間」を設定し、物件画面でもその範囲だけを選べるようにする。オーナー提示の前提なら、UHは10年まで、HSC／SHSは30年までとなる。保存・延長・各取込みも同じ設定を参照する方式を推奨候補とする。現在のUH名称による個別判定からの置換は未決定。

これはグループの上限であり、HSC／SHSの全物件を30年へ変更する案ではない。物件ごとの20年／30年の選択、初回10年、10年単位の延長、既延長年数未満へ上限を下げられない既存仕様を区別して扱う。等級や資材から通常登録の適用条件を自動判定する承認でもない。

採用時は、設定可能値・初期値、グループ変更／名称変更、下書き、本登録、既存物件編集、延長、CSV取込みの扱いを統一する。既存物件に上限超過があるかは別途確認し、設定変更だけで既存の保証期間や満了日を短縮しない。既存データの補完・変更手順と検証を設計してから実装する。
