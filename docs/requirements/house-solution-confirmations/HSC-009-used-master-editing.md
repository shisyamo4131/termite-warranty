# HSC-009: Editing Masters Already Used by Cases

- Status: Not yet asked
- Decision owner: House Solution

## Confirmed Context

Referenced masters are inactivated rather than physically deleted. Property homeowner and construction-company references remain editable and do not rewrite existing cases. Other post-use edit limits have not been confirmed.
