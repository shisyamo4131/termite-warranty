# 0043 保証接頭辞の完全一致と既存ID維持

2026-10-13現在：本件はDev反映・開発側受入れ済み。以降の未反映・禁止は当時の状態。実データの延長履歴は0件で申込日補完は不要。HS業務受入れは別途。[導入結果・確認範囲](../operations.md)。

2026-10-13追加承認：保証接頭辞は前後空白除去後、英大文字・数字・ハイフンの1,499文字以内（空欄可）。保存と再有効化で超過を拒否し、既存値・発行済み番号を切り詰めたり書き換えたりしない。Firestoreの検索対象文字列上限への対応で、完全一致・同時確定・使用先記録なしを維持する。

- Date: 2026-10-13
- Status: Accepted
- 根拠：同日のオーナーが、使用先記録なし・既存ID維持・末尾ハイフンを別物とする仕様・番号不変・Local改修と同時登録検証を明示指示。Dev反映は禁止。

保証グループの重複確認は同一接頭辞だけの検索（limitなし）と自己ID除外で行い、保存と同じFirestoreトランザクションで確定する。接頭辞専用の使用先記録は作らない。既存IDを接頭辞へ変換しない。全件取得も従前から同じ取引内にあり、今回の目的は必要な文書だけを読むこと。

接頭辞ごとの予約は既存データ整備・復旧への影響が大きく、必要性が示されていないためR1では不採用。ID置換も参照・採番の移行を伴うため不採用。末尾ハイフンを無視する旧互換規則は撤回し、完全一致の業務識別と新規採番を整合させる。発行済み番号は保存値を維持する。

通常編集の後勝ち（ADR0016）と、同一接頭辞の別グループ新規作成の拒否を区別する。独立接続による同時登録を検証してから技術完了を判定する。[仕様](../specification.md)、[設計](../design/master-code-read-reduction.md)、[工程](../roadmaps/master-code-read-reduction.md)。
