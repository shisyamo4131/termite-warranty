# ADR0049: Local郵便番号データの自動更新

2026-10-20後続決定：本人Local受入れ完了。zipcloudへの切替をコミット・pushしてDevへ配備する承認を受領。旧日本郵便CSV方式のJSON同梱データ、Hosting provider、CSV更新ツール、Local自動更新module／UI／専用試験／Local保存データを削除する。以下の旧実装・保全方針は過去の記録。復帰が必要な場合はGitの旧版から通常の改修・検証を行う。Prod配備とバックアップ・PITR・Auth退避は対象外。

## 決定

Local起動時と24時間ごとの確認で、日本時間の当月に未確認なら日本郵便の公式UTF-8全国CSVを取得する。失敗時は翌日以降に再試行し、Local停止中の未実施分は次回起動時に確認する。手動の「再確認」はこの待機を省く。

取得・生成・検証後の版だけをGit管理外の`.local-postal/`へ保存し、参照先を一括切替する。追跡中の`public/postal-data/`は初期版として維持。Local専用Nuxt handlerから版固定URLで配信し、開いた画面は次の住所検索で最新版を確認する。登録済み住所と入力済み住所は変更しない。正常な旧版を保持して復帰可能にする。

UIはLocalの管理者ダッシュボードに状態・再確認・旧版復帰を配置。異常時と60日未確認時に警告。メール通知は今回対象外。HTTP操作はループバック、Host、同一Origin、実行時トークンを検査する。これはLocal開発者向け操作であり、クラウドの管理APIやHSアカウントのサーバー認可を追加するものではない。

## 理由・互換性

月次の開発者作業を減らし、未配備のアプリ改修と住所更新が自動で公開されることを防ぐ。既存のHosting配信・手動更新・住所保存形式・候補選択・手入力を維持する。通常ビルドではLocal handlerと自動取得を登録しない。

## 境界・差戻し

Dev／Prodへの自動公開、Git操作、IAM、業務DBバックアップ・PITR・Auth退避は対象外。旧版復帰後は自動更新を一時停止し、明示した再確認の成功で再開。全機能を戻す場合は本変更を差戻し、同梱データを使用する。業務データの移行は不要。
