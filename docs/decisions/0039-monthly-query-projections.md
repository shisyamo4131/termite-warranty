# ADR 0039: 月別対象の検索用項目

- Status: Accepted
- Date: 2026-10-08
- Decision owner: Project owner
- 根拠: 本タスク`01a119fb-27b1-7942-9097-6e7d0d51829a`で月別Firestore取得を明示指示。getAllも採用。

全物件を読んで月別判定する方式を、業務値から計算した保険対象年月範囲・請求年月配列へのクエリに置換する。単純な引渡月一致では過月未報告や延長請求を落とすため、既存判定から検索値を導出する。全保存と同じtransactionで維持し、既存値の補完完了まで月別一覧を公開しない。

検索用項目・索引・移行と復旧時の整合検査が増える。一方、月外の物件本文を取得しない。取得数は請求上のRead数とは別に計測する。検索用項目の削除ではなく旧取得へ戻せるが、旧writer復帰前に準備完了フラグを解除し、再導入時には再移行する。

[設計・移行・検証状態](../design/monthly-queries.md)。業務上の対象判定が変更された場合は導出関数・索引・既存データの再補完を併せて見直す。
