## 受付・反映の進め方

1. 19日までは追加要望の受付を継続する。届いた資料・返信の日付と出典を残し、既存要望との重複を確認して本表へ追記する。
2. 質問・提案・採用済みを分け、未確定事項を実装要件へ自動昇格させない。確定した内容は仕様に記録してから実装・必要検証・Local受入れを行う。
3. 現在の承認は今回変更のコミット・改修ブランチへのpushまで。**Dev配備は行わない**。dev／mainへの統合、Dev配備、HS再確認、Prod反映は今回の完了に含めない。
4. 受付終了後、追加分と回答待ちを含めて残工数・日程を再評価する。19日までの受付継続を理由に、作業済み2件を未着手へ戻したり、全要望対応済みと扱ったりしない。[納品工程](2026-initial-delivery.md)の条件付き日程を維持する。

バックアップ・PITR・Auth退避等は引き続き保留。本書の整理やpushは、保護設定開始・実環境変更の承認を意味しない。
