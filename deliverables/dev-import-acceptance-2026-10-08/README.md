# Dev一括取込み・物件名統合の受入手順

2026-10-08 BRANCH-05追記：同梱CSV／ZIPは配布時点の「支店コード（＊）」見出しを保全した互換資料です。Local改修の新規ダウンロードは「本支店コード（＊）」へ変わり、旧見出しも受理します。Dev反映はまだ行っていません。以下の過去の受入手順は配備済み版に対するものです。

対象はDevだけ。CSVはすべて架空データです。HS提供の実データは回答があるまで取り込みません。基本試験では共通3件＋UH2件を本登録します。301件の拒否試験は登録されません。300件試験は任意の追加検証として分離しています。

## 1. テンプレートを入手する

1. [Dev](https://termite-warranty-dev.web.app)を再読込し、HS管理者でログイン。
2. 「物件・保証」→「一括取込み」を開く。
3. 「共通テンプレートをダウンロード」を押す。「物件保証一括取込テンプレート.csv」がダウンロードされる。
4. 見出し14列に「物件名」が1列あり、「施主名」がないことを確認。UHも同じテンプレート。「外部キー（＊）」列へお施主様契約Noを入れる。ファイル形式はUTF-8のCSV。

今回は下記の用意済みCSVをそのまま使えます。Excelで開いて再保存する必要はありません。

Excelで編集する場合、申込日・引渡日は日付として入力し、年・月・日の順で表示して「CSV UTF-8」で保存してください。「2018/4/1」「2026/01/08」「2026-10-08」を受け付け、プレビューで「2018-04-01」等へ統一されます。年月のみ・存在しない日付・月日年の順・日付の通し数値は受け付けません。外部キー・支店コード・郵便番号は文字列として先頭0を保ってください。

## 2. 検証用の所属を用意する

今回のCSVはR2版です。以前のCSVや登録済みキーは再利用しません。既存の検証グループが住所・資材名必須で作成済みの場合、変更不可のため下記の新名称のグループを作ります。HSC／SHSは外部キー任意のため取込み先には表示されません。

既存の実業務用の工務店や支店と混ぜないよう、以下の検証用データを画面から登録してください。同名がすでにあれば再利用します。

| 共通試験の工務店 | 名称「検証用工務店20261008R2」、上記グループへ所属、有効ON。住所は「東京都」「千代田区」「検証用架空住所1-1」など架空の値 |

| 02-existing-key-reject-2.csv | 共通 | 01の既登録キーを含むため全件棄却。新規キーの行も登録されない |

| 04-unknown-branch-reject-2.csv | 共通 | 未登録支店QA99のため全件棄却。QA01の行も登録されない |
| 05-uh-success-2.csv | UH／UH検証用工務店 | 2件本登録。申込日2026-09-01、引渡日2026-10-01、最長10年。2件目は契約No先頭9997でも支店コード9998で正しく所属。住所・資材名は空欄のまま |

拒否後に入力を変更する場合は「入力を見直す」を使います。通信結果が不明な場合は「登録結果を確認」または「同じ取込みを再送」を使い、新しい取込みとして送り直さないでください。



## 4. 通常入力とグループ設定も確認する

1. 新規物件でHSC／SHS所属工務店を選び、外部キー欄が非表示であることを確認。UH所属工務店を選ぶと「お施主様契約No」が表示され、下書きにも必須になる。
2. UHの通常本登録では住所・断熱材ありの資材名が空欄でも保存できることを架空物件で確認。HSC／SHSでは本登録時に必須であることを確認。
3. 登録済み保証グループの外部キー・住所・資材名の必須スイッチが変更できないことを確認。外部キーの表示名は変更できる。
4. 01・05の物件は初回保証10年であり、最長期間を選択しただけでは延長されていないことを確認。

## 5. 名称統合も確認する

1. 既存物件を開き、一覧・詳細・編集・本登録確認で名称欄が「物件名」一つになったことを確認。
2. 架空の新規取込み物件の物件名を変更して保存し、再読込して変更が残ることを確認。外部キー・保証番号・所属は変えない。
3. 過去履歴に施主名が記録されていたものは「旧履歴の施主名（参考）」として残る。現在の入力項目とは別の旧履歴。
4. 施主電話番号は引き続き独立項目。

## 6. 報告してほしい内容と検証の範囲

01〜06・08〜10の結果、テンプレートのダウンロード可否、名称統合の確認結果をこのチャットへお知らせください。不一致があればファイル名・行・画面の理由だけで調査できます。実データの転載は不要です。

基本CSV試験は5件、通常入力の確認で保存した架空物件は別途増えます。検証用物件は自動削除しません。取消をしても外部キーは再利用できません。再試験用キーの変更や検証データの後片付けは、対象を特定して別途対応します。実業務の保証番号や欠番はCSVに含めていません。

CSV10本は更新後に同梱Spreadsheetライブラリで文字列の往復一致と列数を確認し、現行取込み処理で正常件数・エラーをLocal検証済み（verification.json）。02／04／09はサーバーの既登録キー・所属・保証期間照合をDevで確認する試験であり、LocalのCSV入力検証だけでは拒否されません。**ユーザーのDev受入と300件のDev実行は未実施**です。
